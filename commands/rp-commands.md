# РП команды

| Команда | Описание |
| --- | --- |
| `/город` | Создание, приглашение и выход из города (далее по списку в игре) |
| `/фракция` | Создание и управление фракцией (аналогично городу) |
| `/пернуть` | РП-эмоция |
| `/плюнуть` | РП-эмоция |
| `/profile` | Вся информация о тебе или другом игроке |
| `/marry` | Выйти из брака. Для создания брака нужно создать дорогое кольцо — символ вашей любви |
