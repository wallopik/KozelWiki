# ✏️ Переименование и лор предметов

На сервере можно превращать обычные предметы в **именные RP-предметы**:
менять их название и добавлять к ним авторскую историю.

Для этого используются две отдельные механики:

-   🏷️ **Rename** --- изменение названия предмета;
-   📖 **Lore** --- добавление подписанного лора с автором и датой.

> 💡 Предмет должен находиться в **основной руке**.

------------------------------------------------------------------------

# 🏷️ Переименование предмета

Чтобы изменить название предмета, используйте:

``` text
/rename <название>
```

Например:

``` text
/rename &6Меч Короля
```

После этого предмет получит собственное название.

## 🎨 Цвета

В названии можно использовать цветовое оформление.

Примеры стандартных цветов:

``` text
&a Зелёный
&b Голубой
&c Красный
&d Розовый
&e Жёлтый
&f Белый
```

Также можно использовать форматирование:

``` text
&l — жирный
&n — подчёркнутый
&o — курсив
&m — зачёркнутый
&k — магический текст
&r — сброс форматирования
```

### 🌈 HEX-цвета

Поддерживаются HEX-цвета:

``` text
/rename &#8B0000Кровавый клинок
```

------------------------------------------------------------------------

# 📖 Лор предмета

Команда `/lore` позволяет оставить на предмете **RP-запись**.

Использование:

``` text
/lore <текст>
```

Например:

``` text
/lore Найден в руинах старой крепости.
```

Плагин автоматически добавляет к предмету блок лора, содержащий:

-   👤 **автора** --- ник игрока, который написал лор;
-   📅 **дату** создания записи;
-   📜 **сам текст**.

То есть игроку не нужно вручную подписывать свою запись --- информация
об авторе и дате добавляется автоматически.

------------------------------------------------------------------------

# ✍️ Изменение своей записи

Если тот же игрок снова использует `/lore` на этом предмете, его
предыдущая подписанная запись заменяется новой.

Это позволяет исправить или переписать собственный лор, не создавая
каждый раз ещё один одинаковый блок.

При этом записи других игроков на предмете сохраняются.

------------------------------------------------------------------------

# 🗡️ Пример RP-предмета

Сначала дадим предмету название:

``` text
/rename &#8B0000&lКровавый клинок
```

Затем добавим историю:

``` text
/lore Найден после битвы у северных ворот.
```

В результате предмет будет иметь собственное имя, а под ним появится
подписанная RP-запись с **автором, датой и текстом**.

------------------------------------------------------------------------

# 💡 Для чего это использовать

Система особенно подходит для:

-   🗡️ именного оружия;
-   👑 исторических реликвий;
-   🎁 памятных подарков;
-   📜 сюжетных предметов;
-   🏆 наград за события;
-   🏛️ музейных экспонатов;
-   🤝 предметов, передаваемых между игроками;
-   📖 создания собственной истории вещей.

Один предмет может со временем получить записи от разных владельцев и
превратиться в настоящую серверную реликвию.

> 📖 Не используйте `/lore` как обычное описание характеристик предмета.
> Эта механика лучше всего подходит именно для **RP-истории и подписи
> владельцев**.
