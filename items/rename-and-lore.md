> На сервере можно превращать обычные предметы в **именные RP-предметы**.
> Менять их название и добавлять к ним авторскую историю.

Для этого используются две отдельные механики:

-   🏷️ **Rename** --- изменение названия предмета;
-   📖 **Lore** --- добавление лора с подписью автора и датой.

> 💡 Предмет должен находиться в **основной руке**, чтобы команды работали.

------------------------------------------------------------------------

# 🏷️ Переименование предмета

Чтобы изменить название предмета, используйте:

``` text
/rename <название>
```

Например:

``` text
/rename &6Меч Короля
```

# 📖 Лор предмета

Команда `/lore` позволяет оставить на предмете **RP-запись**.

Использование:

``` text
/lore <текст>
```

Например:

``` text
/lore Найден в руинах старой крепости.
```

Обратите внимание, что данный плагин автоматически добавляет к предмету никнейм автора и дату подписи.
Вам нужно заполнить только текст.

**✍️ Изменение своей записи**

Если вы повторно использует `/lore` на предмете, его
предыдущая запись заменяется новой.

> Это позволяет исправить или переписать собственный лор.
> Записи других игроков на предмете сохраняются.

## 🎨 Изменение цвета

В названии можно использовать цветовое оформление.

Примеры стандартных цветов:

``` text
&a Зелёный
&b Голубой
&c Красный
&d Розовый
&e Жёлтый
&f Белый
```

Также можно использовать форматирование:

``` text
&l — жирный
&n — подчёркнутый
&o — курсив
&m — зачёркнутый
&k — магический текст
&r — сброс форматирования
```

**🌈 HEX-цвета**

``` text
/rename &#8B0000Кровавый клинок
```

------------------------------------------------------------------------

# 💡 Для чего это можно использовать?

Механика особенно подходит для:

-   🗡️ именного оружия;
-   👑 исторических реликвий;
-   🎁 памятных подарков;
-   📜 сюжетных предметов;
-   🏆 наград за события;
-   🏛️ музейных экспонатов;
-   🤝 предметов, передаваемых между игроками;

Один предмет может со временем получить записи от разных игроков и
превратиться в настоящую серверную реликвию переходящую из поколения в поколение.

> 📖Эта механика лучше всего подходит именно для **RP-истории и подписи
> владельцев**.
