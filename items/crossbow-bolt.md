# 🏹 Арбалетный болт

**Арбалетный болт** — специальный боеприпас для арбалета, предназначенный для борьбы с хорошо защищёнными противниками.

В отличие от обычного снаряда, болт способен **наносить урон сквозь броню**, а после попадания дополнительно накладывает на противника **кровотечение** и **замедление**.

> ⚠️ За повышенную эффективность приходится платить скоростью — арбалет с таким болтом заряжается значительно дольше.

---

# ⚙️ Как создать арбалетный болт

Арбалетный болт **не создаётся в верстаке**.

Для его изготовления используется:

**⚙️ Точильный камень**

Возьмите обычный болт и обработайте его на точильном камне.

**Схема создания:**

**🏹 Обычный болт → ⚙️ Точильный камень → 🔩 Арбалетный болт**

После обработки полученный болт можно использовать в качестве специального боеприпаса для арбалета.

---

# ⏳ Зарядка арбалета

Арбалетный болт значительно тяжелее обычного боеприпаса.

Поэтому при использовании такого снаряда арбалет заряжается:

**в 2 раза дольше**

Это делает болт более требовательным к правильному выбору момента для выстрела.

> 💡 Лучше всего зарядить арбалет заранее, ещё до начала сражения.

Во время ближнего боя долгая перезарядка может стать серьёзным недостатком.

---

# 🛡️ Пробивание брони

Главная особенность арбалетного болта — способность наносить часть урона **сквозь броню противника**.

Это делает его особенно полезным против хорошо экипированных игроков.

Арбалетный болт эффективен против:

- 🛡️ игроков в тяжёлой броне;
- 💎 противников в алмазном снаряжении;
- ⚔️ хорошо экипированных бойцов;
- 🏹 целей, которых необходимо ослабить перед дальнейшей атакой.

**🏹 Выстрел → 🛡️ Бронированная цель → 🔩 Пробивание защиты → ❤️ Урон**

> 🛡️ Даже хорошая броня не позволяет полностью избежать последствий попадания такого снаряда.

---

# 🩸 Кровотечение

После успешного попадания арбалетный болт накладывает на противника:

**🩸 Кровотечение**

Кровотечение продолжает воздействовать на цель уже после первоначального попадания.

Таким образом, противник получает не только непосредственный урон от болта, но и дополнительный негативный эффект.

Это делает болт полезным для постепенного ослабления противника.

> 🩸 Попадание становится особенно опасным в продолжительных сражениях, где каждый потерянный запас здоровья имеет значение.

---

# 🐌 Замедление

Вместе с кровотечением поражённая цель получает:

**🐌 Замедление**

После попадания противнику становится сложнее быстро изменить позицию или уйти от стрелка.

Замедление помогает:

- 🏃 догнать убегающего противника;
- 🏹 подготовить следующий выстрел;
- ⚔️ сократить дистанцию для ближнего боя;
- 🛡️ не дать противнику быстро отступить;
- 👥 помочь союзникам окружить цель.

> 💡 Сочетание замедления и кровотечения делает болт особенно полезным для командных сражений.

---

# ⚔️ Эффекты при попадании

Один успешный выстрел одновременно активирует несколько механик.

**🔩 Арбалетный болт → 🎯 Попадание по цели**

После этого противник получает:

- 🛡️ **урон сквозь броню**;
- 🩸 **кровотечение**;
- 🐌 **замедление**.

Таким образом, болт не просто наносит урон, а серьёзно ухудшает положение противника после попадания.

---

# 🎯 Как правильно использовать болты

Арбалетный болт лучше всего подходит для **заранее подготовленных выстрелов**.

Из-за увеличенного времени зарядки использовать его как обычную стрелу не всегда эффективно.

Оптимальная последовательность действий:

1. 🔩 Подготовьте арбалетный болт.
2. 🏹 Заранее зарядите арбалет.
3. 👁️ Найдите приоритетную цель.
4. 🎯 Дождитесь удобного момента.
5. 🏹 Произведите выстрел.
6. 🩸 Наложите кровотечение.
7. 🐌 Замедлите противника.
8. ⚔️ Продолжите атаку или дайте союзникам добить цель.

---

# 🏹 Первый выстрел

Арбалетный болт особенно хорошо работает как оружие для **первого удара**.

Например:

**👁️ Обнаружили противника → 🔩 Зарядили болт → 🎯 Попали → 🩸 Кровотечение + 🐌 Замедление → ⚔️ Начали основной бой**

Противник вступает в сражение уже ослабленным и с ограниченной мобильностью.

---

# 👥 Командное использование

Арбалетные болты становятся ещё эффективнее при игре группой.

Один игрок может использовать арбалет для ослабления цели, после чего остальные участники группы переходят в наступление.

Пример:

1. 🏹 Стрелок попадает болтом.
2. 🩸 Противник получает кровотечение.
3. 🐌 Его скорость снижается.
4. ⚔️ Союзники начинают преследование.
5. 🛡️ Цели становится значительно сложнее уйти.

> 👥 Особенно полезно против игроков, которые пытаются постоянно держать дистанцию или убегать после получения урона.

# 🔨 Получение

Для создания не нужен отдельный верстак или сложная конструкция.

Вам понадобятся:

- 🏹 обычный болт;
- ⚙️ точильный камень.

После обработки:

**Обычный болт → Арбалетный болт**

Готовый боеприпас можно заряжать в арбалет.

---

# 📖 Краткая памятка

- 🔩 **Арбалетный болт** — специальный боеприпас для арбалета.
- ⚙️ Создаётся при помощи **точильного камня**.
- 🏹 Для создания используется обычный болт.
- ⏳ Арбалет с ним заряжается **в 2 раза дольше**.
- 🛡️ Болт наносит урон **сквозь броню**.
- 🩸 При попадании накладывается **кровотечение**.
- 🐌 При попадании накладывается **замедление**.
- 🎯 Лучше всего использовать для заранее подготовленного первого выстрела.
- 👥 Особенно эффективен в командных сражениях.
- ⚠️ Промах опасен из-за длительной последующей перезарядки.

> 🔩 **Арбалетный болт превращает арбалет в тяжёлое оружие для борьбы с бронированными целями.** Один точный выстрел способен пробить защиту, вызвать кровотечение и не дать противнику быстро уйти с поля боя.
