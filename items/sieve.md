# 🧺 Сито

**Сито** — специальный инструмент для просеивания блоков и поиска дополнительных ресурсов.

Механика работает как расширенная версия археологии и позволяет получать полезные материалы из:

- 🏖️ песка;
- 🪨 гравия;
- 🟫 земли.

> 🏺 По сути, это **Археология 2.0** — вместо поиска только подозрительных блоков вы можете самостоятельно просеивать обычные материалы и получать из них редкую добычу.

---

# ⚒️ Как получить сито

Для начала необходимо создать:

**🔩 Металлическое сито**

После этого его можно использовать для обработки подходящих блоков.

> 💡 Сито не работает само по себе — для просеивания нужно одновременно держать и инструмент, и блок.

---

# 🖐️ Как просеивать блоки

Для просеивания понадобятся:

- 🧺 металлическое сито;
- 🏖️ песок, 🪨 гравий или 🟫 земля.

## Порядок действий

1. Возьмите **сито в одну руку**.
2. Возьмите просеиваемый блок **в другую руку**.
3. Нажмите **ПКМ**.
4. После обработки вы можете получить случайный ресурс.

Схема:

**🧺 Сито + 🏖️ Песок / 🪨 Гравий / 🟫 Земля → ПКМ → 🎲 Случайная добыча**

---

# 🎲 Что можно найти

Во время просеивания можно получить множество полезных ресурсов.

В список добычи входят:

- 🦀 **Кусок клешни краба**
- 🧂 **Морская соль**
- 🐚 **Ракушка**
- ⚙️ **Древние детали**
- 🪱 **Червяки**
- 📜 **Кусок чертежа**
- 🏺 **Черепки кувшинов**

> 🎲 Конкретная добыча зависит от случайности, поэтому для получения редких ресурсов может потребоваться просеять большое количество блоков.

---

# 🦀 Кусок клешни краба

Редкий ресурс, который можно получить через систему просеивания.

Также он связан с археологическими механиками сервера.

> 🦀 Один из примеров ресурсов, которые невозможно стабильно получить обычным ванильным способом.

---

# 🧂 Морская соль

**Морская соль** используется в системе готовки.

Она нужна для:

- 🥩 подготовки мяса;
- 🍲 приготовления супов;
- 👨‍🍳 различных рецептов высокой кухни.

Помимо просеивания, соль можно получить другими способами, но сито позволяет добывать её прямо из песка и других подходящих материалов.

---

# 🐚 Ракушка

**Ракушка** — дополнительный ресурс, связанный с морем и рыбалкой.

Её можно получить:

- 🎣 через рыбалку;
- 🧺 через просеивание.

> 💡 Просеивание позволяет искать морские ресурсы даже без постоянной рыбалки.

---

# ⚙️ Древние детали

Один из наиболее ценных ресурсов, которые можно найти через сито.

**Древние детали** используются в продвинутых системах сервера и улучшении снаряжения.

Получать их можно разными способами, включая:

- 🧺 просеивание;
- 🏺 археологию;
- 🐽 взаимодействие с нюхачами.

> ⚙️ Если вы активно занимаетесь улучшением экипировки, просеивание может стать одним из основных способов фарма древних деталей.

---

# 🪱 Червяки

Во время просеивания можно найти:

**🪱 Червей**

Они используются в новой системе рыбалки.

> 🎣 Без червей нормальная добыча через рыбалку становится недоступной.

Это делает сито полезным не только для археологов, но и для рыбаков.

---

# 📜 Куски чертежей

Через просеивание можно найти:

**📜 Кусок чертежа**

Такие части используются в системе чертежей.

Несколько фрагментов можно объединять для получения полноценного чертежа.

> 💡 Просеивание становится дополнительным способом продвижения к редким и ценным рецептам.

---

# 🏺 Черепки кувшинов

Также через сито можно найти:

**🏺 Черепки кувшинов**

Это археологические предметы, которые можно использовать для коллекционирования и декоративных целей.

> 🏺 Благодаря этому система просеивания связана не только с ресурсами, но и с полноценной археологией.

# ⛏️ Какие блоки можно просеивать

Сито работает с основными рыхлыми блоками:

- 🏖️ **песок**
- 🪨 **гравий**
- 🟫 **земля**

Это позволяет выбирать способ фарма в зависимости от того, каких блоков у вас больше.

> 💡 Если рядом есть пустыня, карьер или большое количество земли, можно быстро организовать отдельное место для просеивания.

---

# 🏭 Фарм через сито

Сито можно использовать как отдельную профессию или производственную механику.

Например:

**⛏️ Добыча блоков → 📦 Складирование → 🧺 Просеивание → 🎲 Редкие ресурсы**

Такой подход позволяет постоянно перерабатывать обычные блоки в более ценные материалы.

---

# 🏺 Археология 2.0

Главное отличие новой системы от обычной археологии заключается в том, что игроку не обязательно искать только специальные подозрительные блоки.

Теперь можно самостоятельно добывать:

- песок;
- гравий;
- землю;

и затем перерабатывать их через сито.

Это делает археологию более доступной и превращает её в полноценный способ фарма.

> 🏺 Исследование мира по-прежнему остаётся полезным, но теперь обычные материалы тоже имеют ценность.

---

# 💡 Советы

- 🏖️ Сохраняйте песок вместо того, чтобы выбрасывать его.
- 🪨 Гравий также имеет дополнительную ценность благодаря просеиванию.
- 🟫 Даже обычная земля может принести полезные ресурсы.
- 📦 Создайте отдельный склад блоков для последующей обработки.
- 🪱 Рыбакам стоит просеивать блоки ради червей.
- ⚙️ Игрокам с продвинутым снаряжением пригодятся древние детали.
- 📜 Не выбрасывайте куски чертежей.
