# 🧺 Сито

**Сито** — специальный инструмент для просеивания блоков и поиска дополнительных ресурсов.

Механика работает как расширенная версия археологии и позволяет получать полезные материалы из:

- 🏖️ песка;
- 🪨 гравия;
- 🟫 земли.

> 🏺 По сути, это **Археология 2.0** — вместо поиска только подозрительных блоков вы можете самостоятельно просеивать обычные материалы и получать из них редкую добычу.

---

# ⚒️ Как получить сито

Для его создания потребуется 8 стали и Rwcjr dthtdrb.

Крафт можно увидеть прямо в Minecraft через команду `/craft recipebook`

---

# 🖐️ Как просеивать блоки

Возьмите в одну руку **металлическое сито**, а во вторую - песок, затем зажмите **ПКМ**.

# 📊 Добыча через сито

| Ресурс | Для чего нужен |
| --- | --- |
| 🦀 **Кусок клешни краба** | Редкие рецепты и ресурсы |
| 🧂 **Морская соль** | Готовка и мясничество |
| 🐚 **Ракушка** | Морские и рыболовные механики |
| ⚙️ **Древние детали** | Продвинутые улучшения |
| 🪱 **Червяк** | Рыбалка |
| 📜 **Кусок чертежа** | Получение чертежей |
| 🏺 **Черепки кувшинов** | Археология и декор |

> 🧺 **Сито превращает обычный песок, гравий и землю в полноценный источник редких ресурсов и делает археологию отдельным способом развития на сервере.**
