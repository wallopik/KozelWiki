# Новые ресурсы

Полный список новых ресурсов сервера и способы их получения.

| Ресурс | Способ получения |
| --- | --- |
| **Морская соль** | Плавка бутылька с водой в печи, либо просеивание песка |
| **Стальной слиток** | Плавка железа в плавильной печи (5 минут) |
| **Кусок каната** | Крафтовый предмет |
| **Прочный канат** | Особый предмет для связывания игрока / привязывания лодки с игроками внутри |
| **Сгоревшее мясо** | Ресурс для печи. Возникает при пережарке мяса без соли |
| **Ракушка** | Вылавливается в рыбалке / можно найти при просеивании песка |
| **Кусок клешни краба** | Археология / просеивание песка |
| **Конопля / табак / семена** | Получаются ломая обычную траву. Вырастив под костром на вспаханной земле, можно получить эти растения |
| **Подсолнечное масло** | Натереть семена подсолнуха на точильном камне. Семечки получаются нажав ПКМ по подсолнуху |
| **Болт** | Создается из стали |
| **Арбалетный болт** | Создается, натирая болт на точильном камне |
| **Мука** | Натереть пшеницу на точильном камне. Чтобы получить обычную — просеять в деревянном сите |
| **Грязные овощи** | Моются, выкинув в воду / нажав ПКМ по котлу с водой |
| **Червивые овощи** | Нажав Shift + ПКМ с мечом в левой руке, можно вытащить червя для рыбалки |
| **Тесто** | Нажав мешком муки по котлу с водой |
| **Кора дерева** | Выпадает с некоторым шансом при обтесывании дерева |
| **Концентрированный опыт** | Выпадает с некоторым шансом при убийстве мобов около скалк-катализатора |
| **Древние детали** | Раскапывание каменистой земли нюхачами, просеивание блоков, археология |
