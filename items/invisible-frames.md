# 🖼️ Невидимые рамки

На сервере можно создавать **невидимые рамки для предметов**.

Такие рамки отлично подходят для декораций, магазинов, интерьеров и красивого размещения предметов без видимой деревянной рамки вокруг них.

---

# ✂️ Как сделать рамку невидимой

Для этого понадобится:

- 🖼️ обычная рамка;
- ✂️ ножницы.

Подойдите к установленной рамке, возьмите ножницы в руку и нажмите:

**Shift + ПКМ по рамке**

После этого рамка получит возможность становиться невидимой.

> 💡 Сама рамка не исчезает сразу — её видимость зависит от того, находится ли внутри неё предмет.

---

# 📦 Поместите предмет в рамку

После обработки рамки ножницами положите в неё любой предмет.

Как только предмет окажется внутри:

**рамка станет невидимой**

При этом сам предмет продолжит отображаться.

Схема:

**🖼️ Рамка + ✂️ Shift + ПКМ → 📦 Положить предмет → 👻 Невидимая рамка**

---

# 👻 Как это работает

Невидимость рамки работает автоматически.

### Если внутри есть предмет

- рамка становится невидимой;
- предмет остаётся видимым;
- создаётся эффект предмета, висящего прямо на блоке.

### Если предмет убрать

- рамка снова становится видимой;
- её можно легко найти и использовать повторно.

> ⚠️ Поэтому не стоит переживать, что после извлечения предмета невидимую рамку будет невозможно найти.

---

# 🔄 Как вернуть рамку

Чтобы рамка снова стала видимой, достаточно:

**вытащить предмет из рамки**

После этого обычная модель рамки автоматически появится обратно.

Схема:

**👻 Невидимая рамка → 📤 Убрать предмет → 🖼️ Видимая рамка**

---

# 🏠 Для чего использовать

Невидимые рамки особенно полезны для декора.

С их помощью можно создавать:

- 🗡️ оружие, висящее на стене;
- 🍎 продукты на кухонных поверхностях;
- 🗺️ карты без видимых границ рамки;
- 🏪 красивые витрины магазинов;
- 🧪 декоративные предметы в лабораториях;
- 🛠️ инструменты на стенах мастерских;
- 📦 небольшие интерьерные детали.

---

# 📖 Краткая памятка

1. 🖼️ Установите обычную рамку.
2. ✂️ Возьмите ножницы.
3. Нажмите **Shift + ПКМ по рамке**.
4. 📦 Положите предмет внутрь.
5. 👻 Рамка станет невидимой.
6. 📤 Вытащите предмет — рамка снова станет видимой.

> 🖼️ **Невидимые рамки позволяют размещать предметы без видимой рамки и создавать намного более аккуратные декоративные постройки.**
