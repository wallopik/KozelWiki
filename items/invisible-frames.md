# 🖼️ Невидимые рамки

На сервере присутствует возможность делать невидимые рамки.

> Для их создания нужно нажать **Shift + ПКМ** по рамке с ножницами в руках.

- Далее, чтобы рамка стала невидимой, нужно положить предмет в рамку.
- Если предмет вытащить — рамка станет видимой.
