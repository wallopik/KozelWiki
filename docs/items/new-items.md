# Новые предметы

## 🦀 Кусок клешни краба

Находится при помощи археологии в подводных ванильных структурах (позже появится в рыбалке).

Из кусочков создается сама клешня краба. Клешня краба увеличивает досягаемость до блоков на 6 единиц.

> Клешня крафтится из трёх кусочков. С крафтом можно ознакомиться в верстаке.

## 🐚 Ракушка

Редкий дроп в рыбалке. Выпадает только самым легендарным рыбакам.

Из ракушки крафтится горн наутилуса. С крафтом можно ознакомиться в верстаке.

### 📯 Горн наутилуса

Даёт эффекты на 1 минуту:

- Водное дыхание
- Дельфинья грация
- Скорость

> ⏰ Перезарядка: 3 минуты.
