# 🍺 Пивоварение — BreweryX

> **Дистилляция** — процесс отстаивания напитка происходит в зельеварке.
> **Варка** — происходит в котле.
> **Отстаивание** — выполняется в построенных бочках из деревянных ступеней (дерево влияет на вкус).
